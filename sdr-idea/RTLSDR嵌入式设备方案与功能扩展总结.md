# RTL-SDR嵌入式设备方案与功能扩展总结

## 一、项目目标

目标是做一台基于 **RTL-SDR + 嵌入式主控 + LCD 显示屏** 的多功能无线信息终端，可接收并显示：

- FM 广播信息
- ADS-B 航空数据
- 实时频谱 / 瀑布图
- 后续可扩展多种无线协议和行业功能

该设备不建议采用纯 MCU 直接连接 RTL-SDR，而应采用 **Linux 嵌入式平台作为主控**，例如：

- 树莓派 4B / CM4
- Jetson Nano / Orin Nano
- RK3566 / RK3568 工控板

原因：
- RTL-SDR 是 USB 高速数据设备
- 频谱、FFT、解调、ADS-B 解码都需要较强算力
- LCD 图形界面绘制也更适合 Linux 平台

```text
        ▼

        │
        ▼
      LCD显示屏
```

## 四、推荐软件架构

建议分为四层：

### 1. 采集层
负责从 RTL-SDR 获取 IQ 数据。

可用组件：
- `librtlsdr`
- `rtl_sdr`

主要能力：
- 设置中心频率
- 设置采样率
- 设置增益
- 获取原始 IQ 数据

---

### 2. 信号处理层

#### FM 链路
- 调谐指定 FM 频点
- 滤波
- FM 解调
- 降采样
- 音频输出
- 计算 RSSI

可用工具：
- `rtl_fm`

#### ADS-B 链路
- 调谐至 1090MHz
- Mode S / ADS-B 解码
- 输出飞机信息

可用工具：
- `dump1090`
- `readsb`

#### 频谱链路
- IQ 分帧
- FFT
- 幅度谱计算
- 映射为 LCD 像素
- 生成频谱和瀑布图

可用技术：
- Python + `numpy`
- C++ + FFTW / KissFFT

---

### 3. UI 显示层

原型阶段推荐：
- Python + `PySide6`
- `PyQtGraph`

产品阶段推荐：
- Qt for C++

可显示：
- FM 信息页
- ADS-B 信息页
- 频谱与瀑布图页
- 扫描结果页
- 设备设置页

---

### 4. 控制层
负责系统交互与模式切换：
- 模式切换：FM / ADS-B / 频谱
- 频率调整
- 增益设置
- 预设频点
- 扫描控制
- 录制与回放

可选输入方式：
- 触摸屏
- GPIO 按键
- 旋转编码器

## 五、关键设计结论

### 1. 单 RTL-SDR 首版建议采用“模式切换”
原因：
- 一个 RTL-SDR 同一时间通常只能关注一个中心频率
- FM 与 ADS-B 频段相差很大
- 单次采样无法同时覆盖

因此首版建议：
- FM / ADS-B / 频谱 三种模式切换使用
- 切换模式时重新配置 RTL-SDR

### 2. 若后续要同时运行多个功能
可以采用：
- 双 RTL-SDR
- 一个专用于 ADS-B
- 一个专用于 FM / 频谱 / 其他协议

### 3. 若要更好的显示体验
建议优先使用：
- HDMI LCD，而不是 SPI 小屏

原因：
- 刷新率更高
- 频谱 / 瀑布图显示更流畅
- UI 开发更方便

## 七、最适合直接增加的功能

### 1. AM / NFM / SSB / CW 多模式接收
在现有 FM 基础上扩展为通用接收机，支持：

- NFM
- USB
- LSB

可显示：
- 当前频率
- 调制方式
- 带宽
- 信号强度
- 频谱与瀑布图

价值：
- 将设备升级为通用宽带无线接收机

---

### 2. RDS 广播信息显示
可在 FM 接收基础上增加：
- 电台名称
- 节目类型
- RadioText
- 时间信息

价值：
- 开发成本低
- 展示效果强
- 非常适合 LCD 呈现

---

### 3. ADS-B 增强显示
在已有飞机列表基础上增加：
- 飞机详情页
- 按距离/高度排序
- 历史轨迹缓存
- 雷达盘显示
- 本地网页查看
- FlightAware 上传能力

---

### 4. 宽频扫描 / 频点发现
增加：
- 指定频段自动扫描
- 发现活跃频点
- 频点收藏
- 峰值记录
- 占用率统计

价值：
- 从“看频谱”升级到“发现信号”

---

### 5. 433MHz / 315MHz ISM 传感器解码
结合 `rtl_433` 可解码：
- 温湿度传感器
- 门磁
- 雨量计
- 无线按钮
- 部分家居遥控设备

可显示：
- 设备 ID
- 温度
- 湿度
- 电池状态
- 上报时间

价值：
- 很适合做家庭 / 物业 / 工业监测扩展

---

### 6. IQ 录制与回放
可增加：
- 当前频段 IQ 录制
- 本地保存
- 回放分析
- 异常信号片段记录

价值：
- 便于调试、教学、问题复现、信号留档

## 九、高阶展示或研究型功能

这些功能适合作为二期/三期功能，不建议首版优先投入。

### 1. DAB / DAB+ 数字广播
可接收数字广播节目并显示节目列表、码率、信号质量。

限制：
- 地域覆盖依赖强
- 在中国大陆通用价值不如 FM 高

---

### 2. NOAA / Meteor 气象卫星图像
可增加：
- 卫星过境预报
- 图像接收
- 云图显示

优点：
- 展示效果非常强

难点：
- 需要专用天线
- 开发复杂度高

---

### 3. GNSS 软解
理论可做：
- GPS / 北斗信号分析
- 时频研究

但不建议首版做产品功能，因：
- 算法复杂
- RTL-SDR 不是最佳平台
- 对时钟稳定度要求高

---

### 4. 协议逆向与数字信号分析
如：
- Unitrunker
- Universal Radio Hacker
- Inspectrum

适合：
- 射频研究
- 教学
- 实验用途

不建议作为首版消费类产品主功能。

## 十四、最终结论

该设备最合理的路线不是使用纯 MCU 直接接 RTL-SDR，而是采用：

- **Linux 嵌入式主控（树莓派 / CM4 / Jetson / RK）**
- **RTL-SDR 作为射频接收前端**
- **LCD 作为本地人机交互显示**
- **FM / ADS-B / 频谱作为首版核心功能**
- **逐步扩展到通用接收、航空监测、无线感知、远程访问等方向**

如果只选一个最有落地价值的组合，推荐优先打造：

## “航空 + 通用频谱 + 433 传感器”的三合一嵌入式终端

它兼顾：
- 可视化效果
- 实用价值
- 技术可行性
- 后续产品差异化空间
